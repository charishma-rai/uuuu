# Typography & Recommended Free Fonts

To maintain the Victorian Noir aesthetic of *Velvet Envelope*, use the following recommended free Google Fonts (.ttf / .woff2):

## Recommended Fonts
1. **Playfair Display** (Headings & Case Titles)
   - *Vibe*: Elegant, high-contrast serif suitable for Victorian chapter titles.
   - *Link*: https://fonts.google.com/specimen/Playfair+Display
2. **Cinzel** (UI Headers & Seals)
   - *Vibe*: Classic Roman / Victorian stone engraving style.
   - *Link*: https://fonts.google.com/specimen/Cinzel
3. **Special Elite** (Typewriter Evidence & Telegrams)
   - *Vibe*: Authentic distressed typewriter font for police reports and evidence notes.
   - *Link*: https://fonts.google.com/specimen/Special+Elite
4. **Courier Prime** (Case Dossiers & Dialogue)
   - *Vibe*: Clean monospace typewriter font for structured suspect dialogue.
   - *Link*: https://fonts.google.com/specimen/Courier+Prime
5. **Pinyon Script** (Handwritten Letters & Wills)
   - *Vibe*: Victorian copperplate cursive handwriting for secret love letters.
   - *Link*: https://fonts.google.com/specimen/Pinyon+Script

Drop font files directly into this directory (`.ttf` format recommended).
