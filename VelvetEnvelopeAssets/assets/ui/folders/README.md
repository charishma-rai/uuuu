# UI Assets - Folders

Place dossier folder overlays, manila envelope graphic assets, and confidential file icons here.

## Recommended Specifications
- **Format**: Transparent `.png`
- **Resolution**: 800x600 px transparent canvas
- **Target Filenames**:
  - `folder_closed.png`
  - `folder_open.png`
  - `confidential_file.png`
  - `suspect_dossier.png`
