# UI Assets - Backgrounds

Place high-resolution desktop backgrounds, noir room backdrop textures, and menu wallpapers here.

## Recommended Specifications
- **Format**: `.png` or `.jpg`
- **Resolution**: 1920x1080 (16:9) minimum, 3840x2160 (4K) recommended
- **Target Filenames**:
  - `main_menu_bg.png`
  - `detective_desk_bg.png`
  - `interrogation_bg.png`
  - `evidence_board_bg.png`
