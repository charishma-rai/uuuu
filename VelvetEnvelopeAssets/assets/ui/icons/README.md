# UI Assets - Icons

Place game UI icons (magnifying glass, padlock, skull, clue marker, fingerprint) here.

## Recommended Specifications
- **Format**: Transparent `.png` (128x128 px or 256x256 px)
- **Target Filenames**:
  - `magnifying_glass.png`
  - `fingerprint_icon.png`
  - `lock_icon.png`
  - `skull_icon.png`
